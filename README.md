# Memory Card Game

基于 C 语言开发的控制台记忆翻牌游戏。

## 游戏介绍

玩家通过翻开卡牌寻找相同数字的卡牌，
完成全部匹配即可通关。

## 当前功能

- 5级关卡系统
- 随机洗牌算法
- 翻牌匹配机制
- 计分系统
- S/A/B/C评级
- 连击系统
- 最佳记录保存
- 时间继承机制

## 操作方式

|按键|功能|
|-|-|
|W|向上移动|
|S|向下移动|
|A|向左移动|
|D|向右移动|
|Space|翻牌|
|Q|退出|

## 开发环境

- C Language
- Visual Studio Code
- Windows Console API
